# Windows PC5

### A PlayStation 5-inspired interface for Windows.

Windows PC5 is an open-source project that aims to recreate the look and feel of the PlayStation 5 home menu as a standalone Windows application.

Built with C# and Windows Forms, Windows PC5 is designed to provide a console-like experience on PC, with controller-first navigation and a familiar home screen layout.

## Features

- PS5-inspired home screen design
- Full-screen console-style interface
- PlayStation DualSense controller support
- Joystick and D-pad navigation
- Customizable interface and themes
- Smooth menu animations
- Windows executable (`.exe`)

*Features are planned and will be added as development progresses.*

## Project Status

**Currently in development.**

Windows PC5 is an experimental project. Features, design, and compatibility may change as development continues.
